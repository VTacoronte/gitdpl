# Catsitter Nahual 🐾

Web de presentación de **Catsitter Nahual**, un servicio profesional de cuidado de gatos a domicilio en Las Palmas de Gran Canaria.

## Descripción

Página web realizada a partir de una plantilla HTML, CSS y JavaScript, personalizada como parte de la tarea de control de versiones con Git y GitHub del módulo Despliegue de Aplicaciones Web (DPL), del CFGS de Desarrollo de Aplicaciones Web.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git y GitHub
